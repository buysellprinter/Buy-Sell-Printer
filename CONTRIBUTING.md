# Contributing to the BuySellPrinter Project

Thank you for your interest in BuySellPrinter (BSP).

This repository currently contains public project information and documentation. It does not contain the private application source code.

## Ways to contribute

- Suggest improvements to public documentation.
- Identify unclear wording or factual errors in production-printing explanations.
- Suggest topics that would help buyers, sellers, print shops or service professionals.
- Share feedback on the project vision and documentation.

## Before submitting a suggestion

- Keep information factual and respectful.
- Do not post personal information, confidential business information, credentials or private customer details.
- Clearly distinguish personal experience from independently confirmed facts.
- Do not submit promotional links or unrelated material.

## Feature requests

Describe the problem, who it affects and why solving it would help the production printing community. A suggestion does not guarantee that a feature will be implemented.

Thank you for helping make the project documentation more useful.
