# BuySellPrinter Project Roadmap

This is a high-level direction document, not a promise of delivery dates. Priorities and timing may change as the project develops.

## Current stage

- Website domain acquired
- Initial single-page website created
- Application under development
- Public project documentation being prepared

## Areas being explored

### Production printer marketplace
Support discovery of used and refurbished production printers and help buyers and sellers find relevant opportunities.

### Better machine information
Encourage clearer model, configuration, condition and supporting-evidence information.

### Parts and service discovery
Explore ways for users to find relevant parts suppliers, engineers and technical services.

### Industry knowledge
Develop educational content related to production printing, machine selection, maintenance and troubleshooting.

### Transaction support
Explore ways to organize communication and relevant transaction steps where BSP offers such services.

## How progress will be communicated

As features become available, the official website should be the source of truth for what users can currently do. This repository may be updated as the project evolves.
